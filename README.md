## Overview
The *Instamart Copilot* project is a comprehensive data science and AI engineering capstone designed to build a fully reproducible data pipeline, an automated customer support triage system, a customer segmentation and churn prediction model, and an AI-powered policy RAG and refund agent. All operations run offline using modular scripts, SQLite, and mock LLM tool-calling architectures, with all monetary values tracked in INR.
